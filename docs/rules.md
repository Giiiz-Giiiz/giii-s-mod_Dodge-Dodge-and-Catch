# 規則と入力の仕様

数値はプレイテスト前の初期値。変えるときは `app/ddc/world.lua` の定数と `tests/test_world.lua` を合わせて直す。

## ゲーム（`app/ddc/world.lua`）

- 60 Hz の固定 tick。描画（実機は約 30 fps）とは別に進め、1 frame で最大 8 tick。それ以上の停止は早送りせず捨てる。
- 乱数は xorshift32。seed は run ごとに `math.random` から取り、ログ（`RUN seed=`）に出す。同じ seed と同じ tick ごとの入力なら、同じ build で同じ展開になる（`digest()`）。
- 画面 320×240、上 18 px は HUD。宇宙船の当たり半径 7 px、最高速 170 px/s。
- いん石：半径 6／9／13。Lv は 15 秒ごとに上がる（最大 10）。間隔 `max(14, 48 − 4·Lv)` tick、速さ `70 + 14·Lv` px/s。Lv3 から 2 つ並び、Lv4 から斜め、Lv6 から隙間 1 つの横一列（最初は Lv6 の 5 秒後、以後 10 秒ごと）。当たり判定はいん石の見た目の半径の 0.85 倍。
- アイテム：4〜7 秒ごと。バリア 35%、スター 65%。種類は `ITEMS` 表に足せば増やせる。
- 得点：生き残り 0.1 秒ごとに 1、スター 50、バリア 10。

### バリア

| 場面 | 結果 |
|---|---|
| 取る | 回数 +1（上限 2）、残り時間を 8 秒に戻す |
| バリアありで被弾 | 回数 −1、そのいん石は消える、1 秒無敵（点滅）。0 回になったら時間も 0 |
| 無敵中に重なる | 何も起きない（いん石は通り過ぎる） |
| 8 秒経過 | 回数 0（`expire`） |
| バリアなしで被弾 | ゲームオーバー |

### 1 tick の処理順

1. 宇宙船を動かす（画面内に制限）
2. いん石・アイテムを動かし、画面外を消す
3. **キャッチ**（被弾より先：同じ tick でバリアを取れば助かる）
4. **被弾**：1 tick に 1 回まで。複数が重なっても消費は 1 回で、残りは無敵が守る
5. 無敵・バリアの時間、得点
6. 出現（次の tick から動く）

すり抜け防止：宇宙船と物体の相対運動の線分で最短距離を測る（swept circle）。1 tick に 50 px 動くいん石でも当たる。

## 傾き入力（`app/ddc/tilt.lua`）

```
gyro / accel（screen frame、t_us 付き）→ ジャイロのバイアス補正 → 姿勢（上向きベクトル）
→ 中立の持ち方との差（roll / pitch）→ 遊び・最大角・カーブ → 反転・軸 → 平滑化 → 論理入力 [-1, 1]
```

- **姿勢**：「上」の向きだけを持つ。ジャイロで回し（`dg = −ω × g · dt`、dt は sample の時刻差）、加速度で重力へ寄せる（時定数 0.5 s。|a| が 1 g から外れるほど弱める）。yaw は使わないので磁気センサーは不要。
- **モード**：6 軸（標準）／ジャイロのみ（診断：ドリフトが見える）／加速度のみ（比較）／タッチ（代替）。ジャイロ実機試験の合格経路は 6 軸だけ。
- **中立**：校正を終えた時点の持ち方。「中央を再設定」で変える。アプリ内だけの値で、OS の校正や他のアプリには触れない。
- **バイアス**：起動時、0.6 秒静止したら平均を採る。動いたらやり直す（動きの中で測った値を確定しない）。4 秒後からタップで省ける（未確定と表示）。
- **異常**：最新 sample が 300 ms より古い、NaN、quality が UNRELIABLE 以上 → プレイ中なら一時停止、カウントダウンは進めない。正常な sample が来れば解除。100 ms を超える sample 間隔は積分しない。
- **再開**：HOME・スリープで sensor を閉じ、戻ると姿勢を加速度から取り直す（中立は保つ）。再開はカウントダウンから。
- IMU が開けないとき、値が 1 つも来ないまま校正を省いたときはタッチ操作になる。

## 診断とログ

- 診断表示：モードと状態、バイアス、raw ジャイロ・加速度と sample age、上向きベクトル、絶対／相対の傾き、論理入力、frame 時間、tick 数、積分しなかった間隔、欠測。
- ログ（`giii logs`）：`STATE`、`RUN seed=`、`EV <tick> <kind>`、毎秒の `STAT`（位置・入力・ヒープ）、`OVER score= digest=`、`PAUSE sensor`。
- IMU 記録：`IMU <t_us> <1=accel|2=gyro> x y z 0`。`scripts/log2trace.py` で simulator の `--sensors` に変換する。
